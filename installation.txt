Troubleshooting:
- Authentication failed: verify database user, password encoding and roles.
- Server timeout: check cluster resumed, DNS/network and allowed public IP.
- Plugin read-only: adjust organization AI access; backend still needs its
  own database user even if the plugin connects successfully.
- Queued work: ensure Redis, dispatcher and worker all run on Redis DB 1.
- Port in use: inspect the existing process before starting another one.
- Missing accounts after switching: migration/seeding may not be complete.
- Never put Atlas credentials into VITE_* variables or tracked .env files.
